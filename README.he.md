# סדנאות יצירה

דף נחיתה לסדנאות יצירה לילדים -- קומיקס, איור ואנימציה. כולל עיצוב צבעוני בעברית (RTL) עם אנימציות חלקות ועיצוב מותאם מובייל.

## תכונות

- דף נחיתה בעברית עם עיצוב צבעוני ומודרני
- הצגת תוכניות: קומיקס, איור ואנימציה
- אנימציות חלקות עם Framer Motion
- עיצוב מותאם מובייל (Mobile-first)
- ממשק מודרני עם Tailwind CSS 4

## טכנולוגיות

| טכנולוגיה | שימוש |
|-----------|-------|
| [Next.js 16](https://nextjs.org/) | פריימוורק React |
| [React 19](https://react.dev/) | ספריית UI |
| [TypeScript](https://www.typescriptlang.org/) | בטיחות טיפוסים |
| [Tailwind CSS 4](https://tailwindcss.com/) | עיצוב |
| [Framer Motion](https://www.framer.com/motion/) | אנימציות |

## התקנה

```bash
git clone https://github.com/eladjak/creative-workshops.git
cd creative-workshops
bun install
bun dev
```

פתחו [http://localhost:3000](http://localhost:3000) בדפדפן.
